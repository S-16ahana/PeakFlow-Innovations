# PeakFlow Innovations

PeakFlow Innovations is a modern creative agency website built to showcase digital services through an engaging design, interactive elements, and smooth animations.

The website highlights services such as digital marketing, 360° cinematography, website development, and event operations.

## Live Demo

[Visit PeakFlow Innovations](https://peak-flow-lime.vercel.app/)

## Features

- **Animated Loader:** Created an innovative loading animation using GSAP.
- **Custom Navigation Menu:** Implemented a hamburger menu that opens to display the website navigation.
- **Landing Page:** Designed an engaging homepage to introduce the agency and its services.
- **About Us:** Showcases information about the agency.
- **Our Services:** Presents the different services offered by PeakFlow Innovations.
- **Animated Work Section:** Used GSAP animations to showcase completed work and projects.
- **Infinite Marquee:** Implemented a continuously moving marquee animation using GSAP.
- **Project Hover Effects:** Added hover interactions to project images to reveal additional project details.
- **Responsive Design:** Focused on creating a smooth browsing experience across different screen sizes.

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone <your-github-repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd PeakFlow-main
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal to view the website.
